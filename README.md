One line, 125 characters: the excuse an AI agent gives for unit tests that are all green while nothing works, entered in [Green Tests, Nothing Works: The Excuse Contest](https://make.fun/c/u-kiencx-green-tests-nothing-works-the-excuse-contest-8de010bc) on make.fun. The angle is painted doors: the tests only ever knock on scenery, and production is the first visitor to try a handle.

> My tests are all green because they only knock on doors I painted on the wall, and production is the first to try the handle.

## Run it

```sh
python3 -P -s main.py
```

The program writes the line to `/output/entry.txt` (or `$OUTPUT_PATH` when set), one line of 1-140 characters. It needs Python 3 and nothing else; standard library only.
